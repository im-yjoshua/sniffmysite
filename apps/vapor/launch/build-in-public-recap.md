# How SniffMySite got built in one weekend (DRAFT — not posted anywhere)

A short build-in-public recap. Plain language. Joshua: review before posting.

---

I built a startup-roasting website in one weekend. It's called SniffMySite. Here's how.

**Saturday morning: one plan, one rule.** I wrote a master plan doc with 11 tasks, in order. The rule: one task at a time. Finish it, test it, review it, then start the next one. No skipping ahead. That rule saved the whole weekend.

**First: the look.** A fake product-safety lab that tests startups like toasters — paper background, black ink, hazard orange, and rubber stamps that slam onto the page. The whole design hangs off one idea: "we sniff startups so you don't have to."

**Then the engine.** It reads a startup's public landing page and runs six smell checks: hype words, big claims with no proof, empty sentences, sketchy testimonials, hidden prices, stale pages. 0 = smells fine, 100 = pure vapor. I tested it against 20 real startup pages before trusting a single score.

**Then the pages:** a scan page with an animated report, a leaderboard, a report page for every startup, shareable cards, and a way for companies to claim their page with a DNS check.

**Then the boring-but-important stuff:** payments (in test mode — real money only when the payment company approves us), rate limits, bot protection, security headers. The kind of work nobody screenshots but everybody needs.

**The best part was the feedback rounds.** My first name for it — VaporRank — "doesn't make sense, not memey enough." So it became SniffMySite. Then: "make the copy simple enough for a 5th grader." Then: "make the stamps bigger." Then: "the numbers don't make sense." Each round made it better. Taste is a feature.

**Who did what:** my AI coding partner built every task — 240+ automated tests, screenshots at phone/tablet/desktop, the works. I made the taste calls: the name, the stamp sizes, the words. It's a real partnership: it types fast, I decide what's good.

**Still to do:** buy the domain (sniffmysite.lol), put it on the internet, get payments approved. The link drops when it's real — this whole thing is a weekend experiment, and I'm not pretending otherwise.

"No startups were harmed. Several were exposed."
